# Punto de Juego · Portal de juegos (AEA2)

Portal de la asociación Punto de Juego. Desde esta versión el listado de actividades se genera con PHP a partir de una lista de datos (`$activitats` en `index.php`).

## Estructura

| Ruta | Contenido |
|---|---|
| `index.php` | Datos y funciones en PHP (arriba), plantilla HTML y CSS en un bloque `<style>` |
| `docs/evidencias/` | Evidencias individuales de cada integrante (no se sirven por web) |

## Versiones

- Entrega estática: etiqueta `v1-estatica` (`git checkout v1-estatica`).
- Versión PHP: rama `master`.

## Despliegue

Apache HTTP Server + PHP-FPM. URL local: `http://localhost/php/AEA2/`.
